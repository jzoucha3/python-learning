# Data Types
- Numbers: integers, floats, and complex
`3, 3.5, 1 + j`
- Boolean: true or false
- List: order collection of items
`[0,1,2]`
- Dictionary: unordered collecction of data in key value pair form
``{'first_name':'James',
'last_name':'Zoucha'
}
-Tuple: ordered collection of diferent data types which can't be modified after creation
`(James, 4, apples)`
- Set: Unordered collection of items only storing unique items
`{52, 9, 41}`
- Use `type()` function to check data type
